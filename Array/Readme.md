# DSA Lab 01

## Overview

This repository contains my work for **Data Structures and Algorithms (DSA) Lab 01**. The lab focuses on building the basic understanding required for working with data structures and algorithms through practical implementation and problem-solving exercises.

The activities covered in this lab were completed as part of my DSA coursework and focus on understanding how data is organized, processed, and manipulated using fundamental programming concepts.

## Objectives

The main objectives of this lab were to:

* Understand the basic concepts used in Data Structures and Algorithms.
* Practice implementing fundamental data-handling techniques.
* Understand how different operations are performed on data.
* Develop problem-solving skills using structured programming.
* Analyze the behavior of basic operations and their execution.
* Strengthen the programming concepts required for upcoming DSA topics.

## Lab Work

During this lab, I completed the assigned activities provided in the laboratory manual. The work involved applying fundamental DSA concepts through practical exercises rather than only studying their theoretical definitions.

Each activity was implemented and tested individually to verify its expected behavior and output.

The completed lab covers the concepts and exercises assigned for **DSA Lab 01**.

## Learning Outcomes

After completing this lab, I gained practical experience in:

* Breaking a problem into smaller logical steps.
* Applying programming concepts to data-related problems.
* Understanding how data can be processed through different operations.
* Writing and testing solutions for DSA-based problems.
* Identifying the expected input, processing, and output of a problem.
* Building a foundation for more advanced data structures and algorithms.
