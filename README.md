## 🧪 DSA Project

### Ransomware Spread Simulator

A DSA-based simulation that models how ransomware can spread through a network of connected systems.

The project applies multiple data structures and algorithms, including:

* Graphs
* BFS
* Queues
* Stacks
* Heaps
* Network traversal
* Priority-based processing

The simulator demonstrates how an infection can propagate from one compromised system to connected systems while using DSA concepts to manage and process the simulated network.
